{{ _('About the project') }}

{{ _('tr02102-audit is an open-source auditor for TLS configurations. It measures what a server accepts, judges the result against five published standards at once, and says what to change.') }}

{{ _('Principles') }} {{ _('How it is built') }} {{ _('Limits') }} {{ _('The lab') }}

{{ _('Principles') }}

{{ _('Measure, do not guess') }}
{{ _('Every protocol version, cipher suite and group is tried in a real handshake. Nothing is inferred from a version banner.') }}
{{ _('Unknown is never a pass') }}
{{ _('What could not be measured is reported as unknown. A check with gaps gets no rating and no passing verdict.') }}
{{ _('Standards are data') }}
{{ _('Each standard is a file of rules under review like code. A rule cites its section and keeps the document’s level: required or recommended.') }}
{{ _('The tool protects itself') }}
{{ _('A hosted scanner could be misused against other networks. Private addresses are refused, every check is recorded, and a threat model covers 28 threats.') }}

{{ _('How it is built') }}

  • {{ _('Python. The TLS handshakes are built by hand, so no library decides what is offered or hides an answer.') }}
  • {{ _('A pure rule engine: the same measurement always gives the same verdict, and a stored check can be judged again.') }}
  • {{ _('The scanner’s facts are checked against OpenSSL on public servers, and the lab servers are scanned on every change.') }}
  • {{ _('This website uses no JavaScript and no tracking. Accounts are stored in SQLite or PostgreSQL; passwords as scrypt hashes.') }}
  • {{ _('Command line, web interface, PDF, JSON and SARIF output come from the same report.') }}

{{ _('Limits') }}

  • {{ _('A report is technical evidence about one address at one moment. It is not a certificate and does not replace an audit.') }}
  • {{ _('It is a view from outside. Servers behind one address may be configured differently.') }}
  • {{ _('Only TLS for now. SSH and IPsec, the other parts of TR-02102, are planned.') }}
  • {{ _('The BSI, NCSC-NL and Mozilla rule sets are still drafts until each rule has been checked line by line against the official document.') }}
