{{ _('How a check works') }}

  1. {{ _('Measure') }}

    {{ _('The scanner opens a few dozen short connections and records which protocol versions, cipher suites and key-exchange groups the server accepts. It measures; it does not guess from a banner.') }}

  2. {{ _('Compare') }}

    {{ _('The same facts are evaluated against each standard. “Must” in the standard is a failure, “should” is a warning, exactly as the document words it.') }}

  3. {{ _('Explain') }}

    {{ _('The report gives an overall rating from A+ to F, a verdict per standard, and for every finding the reason, the evidence and the fix.') }}

  4. {{ _('Check again') }}

    {{ _('Change the server, check it again with one click, and compare the two reports: what was fixed, what is new, what the server accepts now.') }}
