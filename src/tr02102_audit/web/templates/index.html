TLS configuration audit

Check a server's encryption against BSI TR-02102 and other standards.

The scanner connects to a server, records exactly which protocol versions, cipher suites and key-exchange groups it accepts, and evaluates the result against several standards side by side. Every finding cites the section it comes from.

Facts, then judgment

Hand-built TLS handshakes enumerate what the server really accepts. A separate engine evaluates the facts, so one scan can be judged against any number of standards.

Standards as data

Each standard is a YAML file under code review. Adding one needs no code. The comparison view shows where standards agree and where they differ.

Inconclusive is never "pass"

A timeout or dropped connection is reported as inconclusive. Network trouble cannot turn into a clean audit result.
